# Screenshot & Demo Capture Guide

Use these assets for both the GitHub README and the Chrome Web Store listing.

## Before capturing

- Close or hide personal tabs, email, Notion pages, account names, bookmarks, and other private information.
- Use a clean browser profile if possible.
- Keep only NUNU, ChatGPT, and the minimal tabs needed for the demo.
- Use a consistent browser window size.
- Prefer dark mode only if the extension UI and ChatGPT screenshots remain easy to read.
- Do not include DevTools or Chrome extension error pages in public screenshots.

## 01 — Hero

Filename: `docs/images/01-hero.png`

Show in one frame:

- one ChatGPT tab with `⏳`;
- one ChatGPT tab with `✅`;
- NUNU badge with an unread count;
- a desktop completion notification.

Goal: a new visitor should understand the product without reading text.

Suggested caption:

> Run ChatGPT tasks in the background and get notified when they finish.

## 04 — Task Inbox

Filename: `docs/images/04-task-inbox.png`

Prepare at least:

- 1 RUNNING task;
- 2 DONE / UNREAD tasks;
- visible Open buttons;
- visible unread badge.

Goal: demonstrate multi-tab task tracking.

## 05 — Desktop notification

Filename: `docs/images/05-notification.png`

Show a clean desktop notification with:

- task title;
- prompt preview;
- instruction to click and return to the task.

If possible, keep unrelated system notifications out of frame.

## GIF demo

Filename: `docs/demo/demo.gif`

Keep it short: about 8–15 seconds.

Recommended flow:

1. Send a prompt.
2. `⏳` appears.
3. Switch to another tab.
4. Task finishes.
5. `✅` appears and notification is shown.
6. Click the notification.
7. Return to the exact ChatGPT task.

Avoid long waiting periods; edit the recording so the transition from running to completed is immediate.
